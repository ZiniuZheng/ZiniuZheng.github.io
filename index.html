ContextLens

An AI assistant for any web page

Source code ↗

A Chrome extension: select text on any site and a floating panel lets you explain, summarize or rewrite it with OpenAI or Anthropic models, with the answer streaming in token by token — no copy-pasting into a separate chat window.

  • Wrote an incremental Server-Sent Events parser that handles events split across network chunks; closing the panel aborts the in-flight request.
  • Rendered the panel in a closed Shadow DOM so page CSS and scripts can't touch it, and model output as text, never HTML.
  • Kept the API key in chrome.storage.local, used only by the service worker, with host permissions limited to the two model APIs.
  • 26 unit tests and a GitHub Actions pipeline (type-check, test, build) on every push; zero runtime dependencies.
  • TypeScript
  • Chrome Extension (MV3)
  • OpenAI & Anthropic APIs
  • SSE streaming
  • GitHub Actions

OnlineOrder

A food ordering web app, deployed on AWS

Source available on request

Browse restaurant menus, build a cart and check out. A Spring Boot REST backend with a React and Ant Design frontend, backed by PostgreSQL and running on AWS ECS Fargate.

  • Built REST APIs for sign-up, menus, cart and checkout, layered into controllers, services and Spring Data JDBC repositories.
  • Secured endpoints with Spring Security session-based authentication and BCrypt; added Caffeine caching with per-customer eviction on cart updates.
  • Wrote 27 JUnit 5 / Mockito tests for the service layer, including cache tests that verify @Cacheable/@CacheEvict behavior.
  • Containerized with a multi-stage Docker build; GitHub Actions CI runs backend and frontend tests and smoke-tests the running container on every push.
  • Deployed to AWS ECS Fargate behind an HTTPS load balancer with a private RDS PostgreSQL database, with one-command deploy and teardown scripts.

Agent AI

Ask a PDF questions by text or voice

Source available on request

Upload a document and every question gets two answers: one retrieved from the PDF, and one from a live web search run by a GPT-5 agent through an MCP server. Questions can be spoken, and answers read aloud.

  • Built a RAG pipeline with LangChain: PDF loading, 500-character chunking, OpenAI embeddings and an in-memory vector store supplying context to GPT-5.
  • Wrote an MCP server exposing a SerpAPI search_web tool over stdio, and a GPT-5 tool-calling agent that writes its own search queries, using the document title to resolve references like "this paper".
  • Traced intermittent timeouts to SerpAPI stalling on about a third of uncached searches and added hedged requests; RAG and MCP run in parallel with isolated failures, cutting answer time from ~15s to 6–12s.
  • Express backend for uploads and Q&A; React and Ant Design frontend with voice input and spoken answers via the Web Speech API.
  • React

  • GPT-5
  • MCP
